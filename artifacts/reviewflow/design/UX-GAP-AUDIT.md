# ReviewFlow v4 — Screen UX gap audit

Principles: empty ≠ load-error · loading skeletons · confirm destructive · keyboard focus · narrow layouts · one primary CTA · role tokens · 1px dividers over card elevation.

| Screen                          | Gap                                                                                                                                          | Fixed                                                                                                                                                                                                                       | Deferred                                                                                                       |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Overview (`home.tsx`)           | Text “Loading overview…”; Card shadows; error as card+ghost Retry; no Eyebrow; metrics as elevated cards                                     | Skeleton metric grid; EmptyState + primary Retry; Eyebrow + bordered shared-grid metrics; one Continue/Start review CTA (keeps CTA when metrics empty)                                                                      | —                                                                                                              |
| Tasks (`tasks.tsx`)             | Text loading row; empty = inline table copy; no load-error path; no SearchField; card shadows; dual CTAs unclear on narrow                   | Skeleton table; EmptyState for empty queue; EmptyState Retry on load error; SearchField with N of M + Esc clear; Import primary when empty / Evaluate when tasks exist; sticky primary on narrow; borders without elevation | Per-row live-retry consent UX polish                                                                           |
| Trace2Preference (`traces.tsx`) | Text loading/empty; error wash without EmptyState; no-selection panel weak; release/reconcile no confirm; card-like panels; raw muted tokens | List/detail skeletons; empty + no-selection + load-error EmptyStates; Notice for action errors; AlertDialog before immutable release + annotation reconcile; Eyebrow sections; role tokens on chrome                        | Full TraceReview body typography pass (remaining dense assist/quality copy); confirm on every outline download |
| Review (`pages/review/*`)       | Duplicate sticky header + ThemeToggle vs app shell; Copy ID ad-hoc; states not using EmptyState                                              | Non-sticky in-page chrome (no ThemeToggle); EmptyState for queue-clear + load-error (one primary each); CopyControl for IDs/model/evidence; `rf-enter` on task change                                                       | Field wrapper for reason textarea (Field is input-oriented / `h-11`); Undo on success toast (no revert API)    |
| Audits (`audits.tsx`)           | Text loading; empty inline; no list load-error; card shadows; Create always primary with detail                                              | Skeleton table; EmptyState empty; Retry EmptyState on list error; Create demotes when detail selected; detail Submit/Resolve is filled; borders without elevation                                                           | Confirm before Create audit (not irreversible / low risk)                                                      |
| Releases (`releases.tsx`)       | Text loading; empty inline; no load-error; cut without confirm; card shadows                                                                 | Skeleton table; EmptyState empty; Retry on error; AlertDialog before Cut release; Field for name; borders without elevation                                                                                                 | —                                                                                                              |
| Settings (`settings.tsx`)       | Text loading text; Card chrome; no load-error                                                                                                | Skeleton; Eyebrow + bordered definition lists; Retry EmptyState; Open setup docs primary only when credentials missing                                                                                                      | —                                                                                                              |
| not-found                       | CTA label “Go home”                                                                                                                          | EmptyState + shell; **Go to Overview** → `/`                                                                                                                                                                                | —                                                                                                              |
| error-boundary                  | CTA label “Reload”                                                                                                                           | EmptyState + shell; **Try again** → `resetError`                                                                                                                                                                            | —                                                                                                              |

## Notes

- Shared primitives used: `EmptyState`, `Eyebrow`, `Field`/`FieldInput`, `SearchField`, `InlineError`, `Notice`, `CopyControl`, button variants (`default`/`main` 44, `outline` 36, `icon` 32).
- Plum / light / dark themes continue to rely on role tokens (`bg-fill-inverse`, `text-text-*`, `border-line-hairline`, `type-*`, `hatch`).
- Layout remains the framed 1200px hatch shell with sticky app header + mono footer; Review no longer double-sticks a second header.
